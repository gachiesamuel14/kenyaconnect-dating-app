# KenyaConnect Dating App

Location-based matchmaking platform for people in Kenya.

## Features (planned / starter)
- User profiles with photos, age, bio, interests
- GPS / location-based nearby matching
- County filters (Nairobi, Mombasa, Kisumu, Kiambu, etc.)
- Swipe / Like / Match
- Real-time chat (to be added)
- M-Pesa payments for premium (future)
- Safety & reporting

## Tech Stack
- Frontend: Next.js 14 (React)
- Hosting: Netlify
- Database (future): PostgreSQL or Supabase / MongoDB
- Auth (future): NextAuth or Supabase Auth
- Maps/Location: Browser Geolocation API + optional Google Maps

## Local Development
```bash
npm install
npm run dev
```

## Deploy
Connect this GitHub repo to Netlify for automatic deploys.

Starter demo shows mock profiles with location request and county filter.
